迁移建议

从 3.7/3.8 迁移到 3.10+

  1. 使用 list[str] 替代 List[str]（3.9+）
  2. 使用 X | Y 替代 Union[X, Y]（3.10+）
  3. 引入 match/case 替代冗长的 if-elif 链
  4. 使用 TaskGroup 替代 gather（3.11+）

从 3.10 迁移到 3.12+

  1. 使用 type Vector = list[float] 替代 Vector: TypeAlias = list[float]
  2. 使用 class Stack[T]: 替代 class Stack(Generic[T]):
  3. 利用更灵活的 f-string 嵌套能力

面向 3.13+ 准备

  1. 评估是否可以使用 NoGIL 模式替代多进程
  2. C 扩展检查 NoGIL 兼容性
  3. 移除对 distutils 的依赖

面向 3.15+ 准备

  1. 对重型导入模块添加 lazy 关键字，优化应用启动时间
  2. 将全局配置/常量从 dict 迁移到 frozendict，防止运行时篡改
  3. 将 _MISSING = object() 哨兵模式替换为 sentinel("MISSING")
  4. 使用 Tachyon 替代第三方采样分析工具（py-spy 等）
  5. 审查 .pth 文件中的 import 行，迁移到 .start 文件格式
  6. 移除所有未显式指定 encoding 的 open() 调用（配合 -X warn_default_encoding 检测）

废弃与移除项追踪

移除/废弃 版本 替代方案
distutils 3.12 移除 使用 setuptools 或 packaging
asyncio.get_event_loop() 隐式创建 3.12 废弃 使用 asyncio.run()
typing.List/Dict/... 3.9 废弃 使用内置 list/dict/...
typing.Union 3.10 可替代 使用 X | Y
typing.Optional 3.10 可替代 使用 X | None
profile 模块 3.15 废弃 使用 profiling.tracing
.pth 文件的 import 行为 3.15 废弃 使用 .start 文件
PyGILState_* C API 3.15 软废弃 使用新的解释器 Guard/View API
