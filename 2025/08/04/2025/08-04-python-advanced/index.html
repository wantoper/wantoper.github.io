Python进阶

super

在讲super之前有一个很重要的东西：方法解析顺序 MRO(Method Resolution Order)
就是一个继承类中寻找方法时的顺序列表，会按照顺序找到第一个方法并且调用

例如继承关系:
C>B>A 那么C的MRO的顺序就为(C,B,A,object)
D>(B,C)>A 那么D的MRO的顺序就为(D,B,C,A,object)
(先是(D,B,A,C,A,object)，然后A被去重只保留最后一个A变为(D,B,C,A,object))

通过D.__mro__可以获取类的MRO元组(深度优先)

super的定义

  • super是Python中的一个类，并不是关键字、类型
  • super(class,class|object):第二个参数决定了MRO，第一个参数决定了从MRO中哪个元素开始往后找(不包含当前)
  • super()：在无参时super会将当前类放在第一个参数，当前方法的第一个参数放在第二个参数

import优先级

导入语句 查找优先级 是否扫描磁盘 .py 说明
from pkg import x ① __init__.py 中的变量 x → ② 磁盘上的 x.py ✅ 是（备选） 变量覆盖同名子模块
from pkg import *（有 __all__） 按 __all__ 列表逐个：① __init__ 变量 → ② 磁盘子模块 ✅ 是（备选） 只导入列表中的名字
from pkg import *（无 __all__） 仅 __init__.py 中显式定义的变量 ❌ 否 忽略磁盘上的子模块文件
import pkg.x 仅磁盘上的 pkg/x.py 文件 ✅ 是（强制） 无视 __init__.py 中的同名变量
